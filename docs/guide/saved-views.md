# Saved views

Click the **Views** toolbar icon (the bookmark) to save your current setup - filters, coloring, layout, and Focus - as one named view you can jump back to in a single click.

## What gets saved

Clicking **"+ save current view"**, giving it a name, and saving captures:

- every currently **enabled** filter, with its full criteria (not just a reference to it - see "If you edit the original later" below)
- every currently **enabled** Color & size group, same way
- the current **layout** (Force/Hierarchical/Radial/Circular), including which note Radial is centered on if that's the active layout
- the current **Focus** note and hop depth, if Focus is active

Anything not currently active (a disabled filter, a group you haven't turned on) isn't part of the snapshot - only what's actually shaping the graph right now.

## Applying a view

Click a view's **play** icon to restore that exact combination - whichever filters/groups it captured come back enabled with their saved criteria, the layout switches to match, and Focus is reapplied if it had one. The currently-applied view (if any) gets a checkmark in the list.

## Updating a view

Once a view is applied, its row gets an extra **save** icon - "Update with current filter/coloring/layout/focus" - which overwrites that same view with whatever's currently live, instead of creating a new one. This icon only appears on the view you actually applied, not on every row - clicking Update anywhere else would silently overwrite an unrelated view.

## If you edit the original later

A saved view stores a full, independent copy of each filter/group's criteria at the moment you saved it - not just a link back to the live filter/group. If you later edit that same filter in the Filter panel, applying the saved view restores its own saved definition, not whatever the filter currently looks like. This is deliberate: a saved view is a snapshot of "what I was looking at," not a live pointer that could silently change out from under you.

## Renaming and deleting

Each row's pencil icon renames it in place; the trash icon deletes it (with a confirmation). Up to 10 saved views at a time.
