features:
  - icon: 🕸️
    title: One graph, your whole vault
    details: Open it from the ribbon icon or the "Open graph" command - every note and link, laid out automatically, no setup required.
  - icon: 🧭
    title: Four layouts
    details: Force-directed (clusters related notes together), Hierarchical (top-down outlines), Radial (rings out from one note), or Circular - a dialog explains what each is for.
  - icon: 🔍
    title: Named, reusable filters
    details: Build filters from tags, properties, folder, filename, text, link count, or how recently a note (or its neighborhood) was edited - invert any of them, and combine several filters with either/or logic.
  - icon: 🎨
    title: Color & size by your own rules
    details: The same criteria as filtering, applied as named, colored groups instead - so "everything tagged #project" gets its own color and size at a glance.
  - icon: 🕰️
    title: Watch your vault grow
    details: The Timeline panel replays notes and links in the order they were created, at a duration and pace you pick.
  - icon: 🎛️
    title: Live appearance tuning
    details: Node/edge size, color, physics, and label density are all adjustable while watching the graph react immediately.
  - icon: 🖱️
    title: Click, hover, drag
    details: Click a node to open that note, hover to highlight its connections, drag a note to pin it exactly where you want it.
